Capabilities
Everything in one place
🎙️

Voice-cloned narration

Chatterbox TTS runs locally. Drop a 5-second WAV into voice_registry/ — it's cast immediately, no training needed.

🧠

Smart format detection

No dropdowns. The brain reads your prompt and auto-selects content type, language, art style, music genre, and voice cast.

🖼️

4K character-consistent art

FLUX.1 hero reference → DreamShaperXL Lightning + IP-Adapter (weight 0.62) → Real-ESRGAN 4K upscale.

🎵

Self-learning music engine

10 built-in genre profiles. New moods are composed procedurally and indexed for future reuse — gets better over time.

🔀

Zero-cost LLM routing

OmniRoute (your keys) first, FreeBuff 100% free fallback second. The pipeline never hard-blocks on a paid API.

📦

Ships both formats

4K 16:9 (3840×2160) for long-form YouTube. 4K 9:16 (2160×3840) for Shorts. Same pipeline, one flag.

Get started in 3 commands

Ubuntu 22.04+ · AMD ROCm or NVIDIA CUDA · Python 3.10+

$ git clone https://github.com/LearnAiWithLalit/LR-Bharat-Studio.git
$ bash setup.sh
$ python3 run.py --prompt "Hindi kids story about a magical forest"
